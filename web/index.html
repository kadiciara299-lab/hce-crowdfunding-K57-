🦊 Cách kết nối MetaMask nhanh chóng & chắc chắn

Trình duyệt Cốc Cốc / Chrome mặc định chặn tiện ích MetaMask chạy trên file mở trực tiếp từ ổ cứng (file:///C:/...). Để bấm nút Kết nối MetaMask bật ví ngay lập tức, hãy dùng 1 trong 3 cách sau:

Cách 1: Mở qua đường dẫn Localhost (Nhanh nhất)
1. Chạy lệnh trong Terminal tại thư mục dự án: npx http-server -p 8080 hoặc python -m http.server 8080.
2. Mở trình duyệt tại: http://localhost:8080/web/web2.html

Cách 2: Dùng VS Code Live Server
1. Mở file web2.html bằng VS Code.
2. Nhấn chuột phải vào code → Chọn Open with Live Server.

Cách 3: Bật quyền truy cập file cho MetaMask
1. Vào Cài đặt tiện ích trình duyệt (chrome://extensions hoặc coccoc://extensions).
2. Chọn Chi tiết ở tiện ích MetaMask → Bật "Cho phép truy cập vào các URL của tệp" → Tải lại trang.
