🦊 Cách kết nối MetaMask nhanh chóng & chắc chắn

Trình duyệt mặc định chặn tiện ích MetaMask chạy trên file mở trực tiếp từ ổ cứng (file:///...). Để bấm nút Kết nối MetaMask bật ví ngay lập tức, hãy dùng 1 trong 3 cách sau:

Cách 1: Mở trực tiếp trên GitHub Pages (Khuyên dùng)
Truy cập đường dẫn công khai: https://kadiciara299-lab.github.io/hce-crowdfunding-K57-/web/index.html

Cách 2: Chạy Localhost
Chạy lệnh npx http-server -p 8080 tại thư mục dự án rồi mở http://localhost:8080/web/index.html

Cách 3: Mở bằng trình duyệt trong ứng dụng MetaMask trên điện thoại
Mở app MetaMask → chọn tab Trình duyệt (Browser) → dán link GitHub Pages ở Cách 1.
